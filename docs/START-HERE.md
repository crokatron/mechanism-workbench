# Mechanism Workbench: start here

**Continuing this tool? Read [the detailed handover](HANDOVER.md).** For pictures and operation, use the [manual](USER-MANUAL.md) and [offline demo](../demo.html).

Editable mechanism examples and door-motion studies with sampled travel, envelopes and comparisons. The demo solves a small slider-crank rather than implementing every production mechanism.

**Start with:** Compare a mechanism. Search by name or choose a category, then select a built-in mechanism.

**Source:** this is a private source checkpoint, not a live-system mirror. Check [the source manifest](../SOURCE-MANIFEST.json) and current working files before merging.

**Keep your work safe:** Defaults are browser-local. Export/import carries the workspace between devices. A CSV records motion results but does not necessarily preserve every editable setting.

**Next maintainer action:** Verify limiting positions and invalid-link geometry using known cases; reload an exported workspace before clearing browser data. Sampled envelopes do not prove full 3D clearance or structural strength.
